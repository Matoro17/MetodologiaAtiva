# 📊 Eletric Blue Jogos - Estratégia e Expansão

## Visão da Editora

**Missão**: Democratizar educação através de jogos analógicos acessíveis que promovem aprendizado ativo, desenvolvimento psicomotor e engajamento real em sala de aula.

**Público-alvo**: 
- Educadores (professores, gestores, coordenadores)
- Escolas (públicas e privadas)
- Programas de educação não-formal
- Comunidades educacionais

---

## 🎯 Modelo de Negócio: Print & Play

### Proposta Única

Você não está vendendo jogos impressos—está vendendo **autonomia e acessibilidade pedagógica**.

Diferenças contra concorrentes:

| Aspecto | Editoras Tradicionais | Eletric Blue Jogos |
|--------|----------------------|-------------------|
| Distribuição | Importação, logística cara | PDF digital, impressão local |
| Custo | Alto (markup + frete) | Mínimo (impressão escolar) |
| Customização | Impossível | Totalmente customizável |
| Adoção em escolas | Processo longo, comitês | Decisão individual de professor |
| Impacto pedagógico | Incerto | Validado em campo |
| Facilidade de atualização | Lenta (novo run de impressão) | Imediata (novo PDF) |

## 💰 Estrutura de Preços

### Modelo de Receita em Camadas

```
1. GRATUITO (Aquisição)
   ├─ Dengueside Survival (versão completa)
   │  └─ Objetivo: Educadores experimentem, criem demanda
   │  └─ Estratégia: Word-of-mouth, validação em escolas
   │
2. BAIXO (Experimentadores)
   ├─ Pacote individual PDF ($5-15 BRL)
   │  ├─ Dengue Blitz
   │  ├─ Blind Code
   │  ├─ Próximos jogos
   │  └─ Formato: Download imediato, arquivo editable
   │
3. MÉDIO (Escolas)
   ├─ Licença Educacional Escolar ($50-150 BRL/ano)
   │  ├─ Acesso a toda biblioteca de PDFs
   │  ├─ Direito de imprimir para todos os alunos
   │  ├─ Atualizações de conteúdo
   │  └─ Suporte por email
   │
4. ALTO (Kits Prontos)
   ├─ Caixas impressas e cortadas ($80-200 BRL/jogo)
   │  ├─ Capa customizada
   │  ├─ Componentes plastificados (durabilidade)
   │  ├─ Manual pedagógico incluído
   │  └─ Frete para instituição
   │
5. PREMIUM (Consultoria)
   ├─ Workshop presencial ($500-1000 BRL)
   │  ├─ Treinamento de professores
   │  ├─ Adaptação de jogos para contexto local
   │  └─ Acompanhamento de implementação
```

### Exemplo de Jornada de Cliente

```

Ama os resultados, quer mais
```

## 🎓 Estratégia de Tração: Validação Pedagógica

### Fase 1: Research & Validation (Agora)

**Objetivo**: Ter depoimentos de 5-10 educadores validando a metodologia

**Ações**:
- Contate professores colaboradores (como Lafayette)
- Peça para documentar implementação em sala
- Colete dados: engajamento, retenção de conteúdo, feedback
- Publique case studies na landing page

**Exemplo de Brief**:
```
Gostaríamos que você implementasse Dengueside com uma turma
e documentasse:
- Antes: Nível de engajamento sobre dengue (quiz rápido)
- Implementação: Como recortaram e jogaram
- Depois: Compreensão de conceitos-chave
- Feedback: Percepção dos alunos

Você recebe acesso gratuito + possível publicação de artigo
```

### Fase 2: Community Building (3-6 meses)

**Objetivo**: Criar comunidade de educadores que usam Eletric Blue

**Ações**:
- Discord/Slack: Grupo privado de educadores
- Newsletter: Tips pedagógicas semanais
- Blog: Posts sobre metodologia ativa + temas dos jogos
- Webinars mensais: Compartilhamento de experiências

### Fase 3: Institutional Partnerships (6-12 meses)

**Objetivo**: Integrar em currículos de escolas/redes

**Ações**:
- Contate secretarias de educação (SME)
- Proponha incorporação em plano pedagógico
- Treine professores coordenadores
- Defina 1-2 jogos por ano letivo como "obrigatório"
